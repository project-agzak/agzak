## 시나리오 1. 게스트 운세 확인

1. **랜딩 페이지**

   * 랜딩 페이지 혹인 로그인 화면에서 `게스트로 오늘 운세 보기` 버튼 클릭
2. **게스트 정보 입력**

   * 성별, 닉네임, 생년월일, 태어난 시각, 태어난 도시 입력
   * `다음 단계로` 버튼 클릭 
   * 웹툰보기 (생략 가능)
   * `운세 카드 확인` 버튼 클릭
3. **게스트 오늘 운세 결과**

   * 오늘의 총운 카드 + 세부 항목(금전·애정·성취·건강) 점수와 한 줄 요약
   * 운세 타입 카드(예: 닭, 궁합 좋은/나쁜 타입) 같이 노출
   * `운세상승 아이템 얻으러 가기` 버튼 클릭 시 회원가입으로 이어질 수 있음

---

## 시나리오 2. 회원가입 및 로그인

### (1) 일반 회원가입 (이메일/비밀번호)

1. **≡(메뉴) → 로그인 / 회원가입 진입**

   * 상단/사이드 메뉴에서 `로그인/회원가입` 버튼 클릭
2. **회원가입 탭**

   * 이메일, 비밀번호 입력 또는 카카오 로그인
   * 닉네임, 성별, 생년월일, 태어난 시각, 태어난 도시 입력
   * `회원가입 완료` 버튼 클릭 → 성공
3. **로그인**

   * 방금 가입한 이메일/비밀번호로 로그인
   * 로그인 성공 시 메인(오늘 운세 점수) 화면으로 이동

### (2) 마이페이지에서 기본 정보 수정

1. **≡(메뉴) → 마이페이지 진입**

   * 닉네임, 태어난 시간 등 표시
2. **정보 수정**

   * 닉네임, 태어난 시간 등 수정 후 저장
   * 저장 후 프로필·운세 계산 시 반영

---

## 시나리오 3. 회원 오늘 운세 확인

1. **≡(메뉴) → 운세보기 또는 메인 페이지 `운세 확인`**

   * 로그인된 상태에서 `운세 확인` 버튼 클릭
2. **오늘 운세 생성/조회**

   * 총운 점수 + 4가지 항목(사랑·금전·성취·건강) 카드
   * 각 카드에 한 줄 설명 표시
3. **카드 플립(뒤집기)로 상세 피드백**

   * 카드 클릭 시 세부 설명(문장 여러 줄) 표시
4. **운세 타입 및 궁합**

   * 오늘 운세 타입(예: 닭) 카드
   * 잘 맞는 타입 / 잘 안 맞는 타입 표시

5. **`운세 상승 아이템 얻으러 가기`, `공유하기`**

   * 운세 강화하기 페이지로 이동
   * 내 운세 딥링크 공유하기 가능

---

## 시나리오 4. 운세 강화 게임 (쿠키 굽기)

1. **메인 페이지 또는 ≡(메뉴)에서 `운세 강화` 진입**

   * 남은 게임 횟수(오늘 n / 최대 10회) 표시
2. **게임 시작**

   * `운세 강화` 버튼 클릭 → 오늘 세션 시작 또는 진행 중 세션 재개
   * 초기 성공 확률, 오늘 남은 세션 수 표시
3. **강화 시도 10회 진행**

   * 강화할 항목 선택 (사랑·금전·성취·건강 또는 액운)
   * 불 세기 선택 (예: 약불/강불)
   * `원하는 행운` 버튼 클릭 → 성공/실패 연출, 해당 항목 점수 변동
4. **위험 조절 (액운 상승 선택)**

   * 확률이 점점 낮아지면 액운 버튼을 눌러 점수 확보
5. **10회 종료 후 결과**

   * 포춘쿠키 획득 연출
   * 어떤 쿠키를 얻었는지(이름, 능력치) 보여줌
   * 쿠키는 인벤토리에 자동 추가
6. **게임 횟수 증가 (메인 페이지)**

   * `공유하기` 버튼 클릭 → 강화 잔여 횟수 +1 증가

---

## 시나리오 5. 운세 강화 (쿠키 먹기)

1. **≡(메뉴) → 쿠키 먹기 / 인벤토리**

   * 보유 중인 포춘쿠키 목록 표시
2. **쿠키 하나 선택**

   * 쿠키 상세 보기: 이름, 희귀도, 능력치(사랑·금전·성취·건강), 생성 일시
3. **쿠키 먹기(사용)**

   * `쿠키 먹기` 버튼 클릭
   * 오늘 운세에 해당 쿠키의 능력치가 즉시 반영

4. **쿠키 버리기(삭제)**

   * `🗑️(휴지통)` 버튼 클릭
   * 해당 쿠키 삭제

---

## 시나리오 6. 월별 운세 조회 (캘린더+그래프)

1. **≡(메뉴) → 운세 달력**

   * 이번 달 달력 표시
   * 오늘 날짜 강조
2. **특정 날짜 클릭**

   * 선택한 날짜의 상세 운세(총운 + 세부 항목) 표시
3. **기간별 그래프**

   * 이번 주 기간 선택
   * 기본 운세 vs 쿠키/게임으로 강화된 운세 점수 비교
   * 날짜별 원본 점수 vs 최종 점수 막대 그래프로 확인

---

## 시나리오 7. 쿠키 도감

1. **≡(메뉴) → 쿠키 도감 진입**

   * 상단 햄버거 메뉴에서 `쿠키 도감` 선택
2. **도감 요약 확인**

   * 상단에서 `모은 쿠키 10 / 13`처럼 수집 현황 확인
3. **선반 형태의 쿠키 리스트 확인**

   * 모은 쿠키는 컬러, 못 모은 쿠키는 `???` 회색 실루엣으로 표시
4. **쿠키 상세 보기**

   * 예: `건강 쿠키` 터치 → 말풍선으로 레시피/효과, 희귀도(UNIQUE 등) 표시

---

## 시나리오 8. 쿠키 선물하기 & 알림

1. **≡(메뉴) → 쿠키 먹기 / 인벤토리 진입**

   * 보유 중인 포춘쿠키 카드 리스트 확인
2. **쿠키 선택 → 선물하기**

   * 예: `믹스 쿠키` 선택 → `쿠키 선물하기` 버튼 클릭
   * 팝업에서 받는 사람 닉네임 검색, 응원 메시지 작성 후 `전송` 클릭
3. **친구 계정에서 알림 확인**

   * 친구 계정 로그인 → `🔔(알림)` 열기 → `선물 알림` 카드 확인
4. **선물 상세 & 수락**

   * 알림 클릭 → “OO님이 보낸 쿠키” 팝업에서 메시지와 쿠키 이미지 확인
   * `쿠키 확인` 클릭 → 인벤토리에 추가
5. **인벤토리/도감에서 반영 확인**

   * 다시 `쿠키 먹기` 또는 `쿠키 도감`에서 받은 쿠키가 생긴 것을 확인

---

## 시나리오 9. 운세 공유하기

1. **오늘 운세 결과 화면 진입**

   * 메인에서 `운세 확인` 후 결과 화면(상징 동물 + 엇갈린 친구 카드) 확인
2. **공유 버튼 클릭**

   * 하단 `운세 상승 아이템 얻으러 가기` 아래 `공유하기` 버튼 클릭
3. **공유 패널 노출**

   * 기본 공유 창에서 아그작 썸네일과 링크 확인
   * 카카오톡, WhatsApp, Gmail 등 채널 아이콘 표시
4. **카카오톡 공유**

   * 카카오톡 아이콘 선택 → 친구에게 링크 전송 가능

---

## 시나리오 10. 랭킹 확인하기

1. **메인 페이지 스크롤 → 오늘의 랭킹 섹션**

   * 리본 배너에 `오늘의 랭킹`, 아래에 `KST 2025-11-19 13:00 기준` 표시
2. **랭킹 기준 탭 확인**

   * `총점 | 원점 | 증가율` 탭으로 각 항목별 순위 확인
     (예: `증가율` 탭으로 전환)
3. **TOP 3 목록 확인**

   * 1~3위는 메달 아이콘 + 닉네임 + 총점
   * 오른쪽에 빨간색 퍼센트(예: `73.3% ↑`) 표시
4. **내 순위 확인**

   * 리스트에서 내 닉네임이 몇 위인지 확인
5. **랭킹과 연동된 정보**

   * 필요 시, 해당 회원의 오늘 운세나 도감으로 이동해 상세 정보도 볼 수 있음을 설명
